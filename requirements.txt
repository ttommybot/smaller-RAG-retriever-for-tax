# RAG for Tax 项目依赖

## 核心依赖
sentence-transformers>=2.2.0    # 本地 Embedding 模型（MiniLM）
pyyaml>=6.0                      # 配置文件加载
requests>=2.25.0                 # HTTP 请求（HuggingFace/阿里云 API）
numpy>=1.20.0                    # 向量运算
scikit-learn>=1.0.0              # 机器学习工具
scipy>=1.7.0                     # 科学计算

## 异步 HTTP 依赖（问题集生成）
aiohttp>=3.8.0                   # 异步 HTTP 客户端

## Web 交互界面依赖
flask>=2.0.0                     # Web 框架（交互式界面后端）
flask-cors>=3.0.0                # Flask CORS 支持（前后端分离）

## 可选依赖
openai>=1.0.0                    # OpenAI 接口（如使用 OpenAI 模型）
dashscope>=1.0.0                 # 阿里云 DashScope SDK（可选，本项目使用 requests 直接调用）
torch>=2.0.0                     # PyTorch（sentence-transformers 会自动安装）
pandas>=1.3.0                    # 数据处理（可选）

## 安装命令
```bash
# 安装核心依赖
pip install sentence-transformers pyyaml requests numpy scikit-learn scipy aiohttp

# 安装 Web 交互界面依赖
pip install flask flask-cors

# 安装全部依赖
pip install sentence-transformers pyyaml requests numpy scikit-learn scipy aiohttp flask flask-cors
```

## 模型下载
```bash
# 下载 MiniLM 模型到本地 models 目录
python scripts/download_models.py
```
